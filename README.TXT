# Bit (Java)

An object-oriented Java class that models a single binary bit (`0` or `1`) and implements logic gate operations for binary addition.

## Features
* **Bit Modeling:** Stores and validates single-bit state (`0` or `1`).
* **Bitwise Addition & Carry Logic:** Implements full-adder/half-adder behavior (`add(Bit b)` and `add(Bit b, Bit c)`) to calculate sums and carry bits.
* **Encapsulation:** Uses clean object-oriented getters, setters, and state management.

## How to Use
1. Open the project in **BlueJ** (or any Java IDE).
2. Instantiate `Bit` objects with initial values `0` or `1`.
3. Call `add()` methods to compute bit addition and extract carry values.

## Tech Stack
* **Language:** Java
* **IDE:** BlueJ
